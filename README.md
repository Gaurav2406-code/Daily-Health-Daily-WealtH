# HealthTrack Pro - Complete Android & Google Play Ready Source Code

## नए जोड़े गए फीचर्स (Final Feature Set):
1. **डार्क मोड / लाइट मोड (Dark Mode Toggle)**: टॉप नेविगेशन बार और सेटिंग्स से थीम बदलने की सुविधा (स्थायी रूप से सुरक्षित)।
2. **आपातकालीन SOS में लाइव लोकेशन**: WhatsApp इमरजेंसी अलर्ट में मरीज की वर्तमान लाइव लोकेशन का Google Maps लिंक स्वतः संलग्न।
3. **कस्टमाइज़ेबल ग्लास/कंटेनर साइज़**: 200ml, 250ml, 300ml मग या 500ml बोतल चुनने की सुविधा।
4. **स्नूज़ बटन (Snooze 10 Min)**: व्यस्त होने पर पानी पीने के रिमाइंडर को 10 मिनट आगे बढ़ाने की सुविधा।
5. **प्राइवेसी पॉलिसी (Privacy Policy & Terms)**: Google Play Store नीतियों के अनुसार इन-ऐप प्राइवेसी पॉलिसी।
6. **Play Store 5-Star Rating**: 5 दिन की स्ट्रीक पूरी होने पर यूज़र को प्ले स्टोर पर 5-स्टार रेटिंग देने का सम्मानजनक डायलॉग।
7. **हार्डवेयर स्टेप्स व ऑटो-लॉगिन**: फोन जेब में रखकर चलने पर लाइव कदम काउंट और ऐप बंद करके खोलने पर सीधे होम स्क्रीन।
8. **HD App Logo & Mipmaps**: Android 8-15 के सभी रेजोल्यूशन के आधिकारिक आइकन्स।

## प्रोजेक्ट संरचना:
- : मुख्य Flet एप्लिकेशन
- : साल्टेड PBKDF2-HMAC-SHA256 पासवर्ड सुरक्षा
- : सेंसर्स, GPS लोकेशन व पुश नोटिफिकेशन्स
- : सुरक्षित Razorpay पेमेंट व वेबहुक बैकएंड
- : Android के सभी HD mipmap आइकन्स व एडैप्टिव XMLs
- : पैकेजिंग व अनुमतियाँ
- : GitHub Actions ऑटोमैटिक APK व AAB बिल्ड वर्कफ़्लो
- : लोकल कंप्यूटर बिल्ड स्क्रिप्ट

## GitHub Actions से नई APK कैसे बनाएँ:
1. इस ज़िप की सभी फाइलों को अपने GitHub रिपॉजिटरी में पुश (Push) करें।
2. Actions टैब में जाकर 5-6 मिनट में तैयार **HealthTrackPro-APK** व **HealthTrackPro-PlayStore-AAB** डाउनलोड करें।
